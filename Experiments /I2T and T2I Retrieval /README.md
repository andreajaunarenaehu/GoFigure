To address cross-modal mapping abilities, we use the well-known image-text retrieval task (Cao et al. 2022). 
In this task, the objective is to assess whether a model can retrieve the corresponding image given a textual description (text-to-image retrieval or T2I for short), and conversely, retrieve the correct text given an image (image-to-text retrieval or I2T for short).

As dual-encoder VLMs are naturally suited for retrieval tasks, we evaluate CLIP (Radford et al. 2021), SigLIP (Zhai et al. 2023), and SigLIP 2 (Tschannen et al. 2025).

- SigLIP evaluation code and its results can be found in SigLIP folder
- SigLIP 2 evaluation code and its results can be found in SigLIP 2 folder
