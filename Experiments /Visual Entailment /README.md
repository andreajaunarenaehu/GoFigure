The Visual Entailment (VE) task (Xie et al. 2019) evaluates the model’s ability to reason about the relationship between a premise and a hypothesis within a visual context.
In this task, given an image and a text (the hypothesis) pair, the model must determine whether the hypothesis is entailed or contradicted by the image.

We evaluate three families of MLLMs: Qwen 2.5 VL (Bai et al. 2025), LLaVA (Li et al. 2024), and Llama 3.2 (Grattafiori et al. 2024) .

In each folder we can find the code to run each model and the results we get with this code.
